# Inferential statistics: original teaching backbone

This outline follows the original four PowerPoint decks. It groups adjacent
slides by topic to expose the teaching sequence. The companion
[inventory](inferential-original-slide-outline.md) retains all 141 slides,
original titles, subtitles and repeated headings. Group descriptions below
summarize the sequence; they are not presented as verbatim source titles.

The source decks use 307102 as their historical course identity. The active
course remains 307312 Applied Statistics — Masters Level.

## How this can guide the next rewrite

- Preserve the four main sections and the original topic order as the starting point.
- Use the grouped topics as the planning units. The 141 source slides are a reference, not a required length for the new material.
- Within each topic, identify the explanation, example, calculation/software and interpretation before writing it.
- Keep source extraction separate from decisions about corrections, replacement datasets and added explanations.
- Review and agree the backbone first; then build one section at a time against it.
