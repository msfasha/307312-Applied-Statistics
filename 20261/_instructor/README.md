# Instructor materials

- `solutions/module01/`: R lesson answers; numbers match Lessons 2–4.
- `solutions/module02/`: answers for Lessons 1–4 and the integrated review.
- `course-plan.qmd`: syllabus/reference mapping.
- `descriptive-statistics-plan.md`: teaching decisions and completion status.
- `book-reference-notes.md`: source verification and figure provenance.
- `data-checks/`: publisher workbook inventory and checked dataset results.
- `source-data/student-measurements.xlsx`: original workbook for the age/height export, preserved unchanged.
- `templates/lesson-template.qmd`: starting source for a lesson.
- `_output/`: generated instructor HTML, produced by `bash scripts/render-instructor.sh`.

These sources are excluded from the student build. Archive and cleanup details are in `../../docs/maintenance/cleanup-report.md`.
