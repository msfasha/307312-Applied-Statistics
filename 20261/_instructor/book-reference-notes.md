# Textbook reference and data notes

This folder adds course planning and an introductory illustrated lesson to the existing 20261 Quarto project. The primary reference is *Essentials of Modern Business Statistics with Microsoft Excel*, 8th edition (2020). R is the analysis language.

## Working files

Active sources live under `modules/`, with one stylesheet at `assets/petra-brand.css` and teaching CSVs under `data/module02/`. Run `Rscript scripts/verify-data.R` for publisher data and `Rscript scripts/prepare-histogram-student-data.R` for the supplementary measurements. Render instructor guides with `bash scripts/render-instructor.sh`. The workbook inventory and verification limits are in `_instructor/data-checks/`.

## Figure sources

`assets/module02/book-fig-2-11.png` is a cropped excerpt of Figure 2.11, printed page 52 / PDF page 84, from the local 8th-edition book; copyright 2020 Cengage Learning. Its caption carries attribution in the lesson. Keep the original figure distinct from original illustrations. No publication or external distribution has been performed.

Petra purple is a thin title accent on pale lavender panels with dark text. Body text stays neutral, and charts use suitable analytical palettes. Original statistical charts are generated by R from the checked CSVs. The sampling diagram is an original SVG. Use image generation only for conceptual illustrations where artistic depiction helps; numerical charts must be computed from data.
